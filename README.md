## ⚡ Features

- 🔍 **Live Device Discovery:** Scrapes and lists all active DHCP clients connected to your Nokia / Airtel ONT router (`http://192.168.1.1`).
- 🚫 **One-Tap Instant Ban:** Block rogue or bandwidth-hogging devices immediately via router MAC filtering rules.
- ⏱️ **Flexible Timed Bans:** Choose between preset durations (1 hr, 2 hrs, 4 hrs, 8 hrs) or enter an arbitrary custom duration (e.g. 0.5 hrs or 12 hrs).
- 🔄 **Autonomous Background Unbans:** Uses Android `WorkManager` with `RECEIVE_BOOT_COMPLETED` so unban tasks run reliably even if the app is killed or the phone is rebooted.
- ⏳ **Live Countdown Badges:** Real-time countdowns on banned device cards showing exactly how much time remains.
- 🔓 **Instant Early Unban:** Manually unban any device on-demand with one tap, canceling the pending background task.
- 🔒 **Zero Hardcoded Secrets:** Credentials are typed interactively and stored in hardware-backed `EncryptedSharedPreferences` (AES-256 GCM).

## ⚙️ Step-by-Step: How to Configure Bouncer for Your Wi-Fi Network

Follow these steps to configure Bouncer to manage your home Wi-Fi network:

### Step 1: Connect to Your Home Wi-Fi
Make sure your Android device is connected to the Wi-Fi network generated by your router (either 2.4 GHz or 5 GHz band). Bouncer interacts directly over your local area network (LAN) and does not require an active internet connection to control the router.

> 💡 **Tip:** Turn off any active VPNs on your phone while using Bouncer so LAN requests to `192.168.1.1` aren't routed outside your home network.

---

### Step 2: Find Your Router's Gateway IP Address
By default, Airtel / Nokia ONT routers use `http://192.168.1.1`. If your router uses a custom gateway:
- **On Android:** Go to **Settings** → **Network & Internet** → **Wi-Fi** → Tap the gear ⚙️ next to your connected network → Expand **Advanced** → Look for **Gateway** (e.g. `192.168.1.1` or `192.168.0.1`).
- **On Windows (PC on same Wi-Fi):** Open PowerShell / Command Prompt, run `ipconfig`, and note the **Default Gateway**.
- **On macOS:** Open Terminal, run `netstat -nr | grep default`, or check **System Settings** → **Network** → **Wi-Fi** → **Details** → **TCP/IP**.

---

### Step 3: Locate Your Router Admin Credentials
The admin credentials for your router are needed so Bouncer can log in and manage MAC access rules:
1. Check the **physical label/sticker** located on the back or underside of your router.
2. Look for fields labeled **Username / Login ID** and **Password / Admin Key**.
3. **Common Default Credentials:**
   - **Username:** `admin`
   - **Password:** `admin`, `password`, or the unique serial/alphanumeric key printed on the ONT sticker.

---

### Step 4: Configure Credentials in the App
1. Launch the **Bouncer** app on your phone.
2. On the **Router Credentials** setup screen:
   - **Router Base URL:** Enter `http://192.168.1.1` (or your gateway IP from Step 2).
   - **Admin Username:** Enter your router username (e.g. `admin`).
   - **Admin Password:** Enter your router password.
3. Tap **Save & Continue**. Bouncer will securely encrypt these credentials on your device using Android KeyStore (AES-256 GCM) and open the device management dashboard.

---

### Step 5: Managing Devices & Setting Bans
- **Refresh List:** Swipe down on the screen or tap the 🔄 icon in the top bar to fetch connected devices.
- **Pause Access (Ban):** Tap **Pause** on any device card. Pick a duration (1 hr, 2 hrs, 4 hrs, 8 hrs, or type custom hours like `0.5` or `6`), then confirm.
- **Auto Unban:** Once banned, the card displays a live countdown timer. When the timer expires, Bouncer's background worker automatically clears the MAC filter rule on your router.
- **Immediate Unban:** Tap **Unban Now** anytime to restore access early.
- **Change Settings:** Tap the **⋮** menu in the top-right corner anytime to update your router IP or password.

---

### 🔧 Customizing for Other Router Models / Firmware
If your router uses a different web interface or firmware layout, you can easily adapt the scraping layer:
1. Open your router's admin panel in a desktop browser (e.g., `http://192.168.1.1`).
2. Right-click and choose **Inspect Elements** (F12) to observe:
   - The form action URL and input field names for **Login** (e.g. `/api/login` or `/login.cgi`).
   - The HTML table `id` or `class` for the **DHCP Client List** page (e.g. `table#dhcp_table`).
   - The API endpoint or form POST for **MAC Filtering / Access Control**.
3. Open [`AOT4221NKRepository.kt`](bouncer-app/app/src/main/java/com/example/bouncer/data/AOT4221NKRepository.kt) and update the endpoint paths and Jsoup CSS selectors to match your router's markup.

## 🏗️ Architecture

```
com.example.bouncer
├── MainActivity.kt              // Compose host & screen crossfade navigation
├── ui/
│   ├── DeviceListScreen.kt      // Material 3 pull-to-refresh & device listing
│   ├── DeviceCard.kt            // Device stats, countdown & action triggers
│   ├── BanDurationDialog.kt     // Preset & custom hours modal
│   ├── LoginSetupScreen.kt      // Router credential entry & validation
│   └── theme/                   // Theme.kt, Color.kt, Type.kt (Dark-first design)
├── data/
│   ├── RouterRepository.kt      // Interface for router communication
│   ├── AOT4221NKRepository.kt   // Concrete implementation for Nokia/Airtel ONT
│   ├── ConnectedDevice.kt       // Model: name, IP, MAC address
│   ├── BanRecord.kt             // Entity: mac, deviceName, bannedAt, unbanAt, workRequestId
│   └── local/
│       ├── BouncerDatabase.kt   // Room DB singleton
│       ├── BanRecordDao.kt      // CRUD & Flow observation
│       └── CredentialStore.kt   // AES-256 EncryptedSharedPreferences wrapper
├── network/
│   ├── RouterHttpClient.kt      // OkHttpClient singleton
│   └── RouterCookieJar.kt       // Session cookie store
├── worker/
│   └── UnbanWorker.kt           // CoroutineWorker scheduled via WorkManager
└── viewmodel/
    └── DeviceListViewModel.kt   // Reactive StateFlow combining Room + Network + Workers
```

## 🚀 Build & Installation

### Prerequisites
- Android 7.0 (API Level 24) or higher.
- Java Development Kit (JDK 17).
- Connected to your router's Wi-Fi network.

### Build from Source
1. Clone this repository:
   ```bash
   git clone https://github.com/ratna3/bouncer.git
   cd bouncer/bouncer-app
   ```
2. Build the Debug APK:
   ```bash
   ./gradlew assembleDebug
   ```
3. Install to your connected device:
   ```bash
   ./gradlew installDebug
   ```
